# Sea Life & Humans – Marine Conservation Awareness Website

This is a static HTML and CSS-based educational website focused on raising awareness about the importance of protecting marine life. The site discusses threats to underwater ecosystems and promotes sustainable practices, policy advocacy, and community engagement.

## 🌊 Project Overview

**"Sea Life & Humans"** is a public-facing informational website aiming to:

- Educate visitors on marine biodiversity and its importance
- Highlight major environmental threats like pollution, overfishing, and climate change
- Promote policy advocacy and community involvement
- Encourage sustainable behaviors and environmental stewardship

## ✨ Features

- Visually appealing gradient background and fade-in animations
- Structured navigation bar with links to different sections
- Detailed, well-organized content covering:
  - Threats to marine ecosystems
  - Advocacy and policy-making
  - Community-based conservation
  - Educational campaigns and sustainable living
- Fixed footer and floating logos for visual branding

## 🛠 Technologies Used

- HTML5
- CSS3 (inline `<style>` tag)
- No JavaScript dependencies

## 🔧 How to Use

1. Download or clone the repository.
2. Ensure all assets (logos, linked HTML pages) are in the same folder.
3. Open `about.html` in your browser.
4. Modify the content as needed for your campaign or educational use.
